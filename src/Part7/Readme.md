Данное задание является опциональным и дает 0.5 дополнительных балла на экзамене

Для выполнения данного задания нужно выполнить следующие шаги
1. Реализовать Functor, Applicative, Alternative, Monad, MonadFail для парсера и написать тесты покрывающие законы классов и корректность реализации
2. Имплементировать предложенные комбинаторы и написать тесты на их работу
3. Написать парсер небольшого языка или формата данных
    1. Выбрать язык или формат данных
    2. Научиться парсить данный язык в синтаксическое дерево используя реализованный парсер и его комбинаторы (можно дописывать свои комбинаторы)
    3. Написать тесты на парсер языка
4. Защитить
